# Security

Please do not post credentials, real server addresses, account data, private keys or unredacted logs in public issues.

For a vulnerability, use GitHub's private vulnerability reporting on this repository when available. Otherwise open an issue containing only a request for a private reporting channel, without exploit details or secrets.

This alpha is intended for evaluation. Review remote commands and use a restricted SSH account. ServerLoom cannot roll back arbitrary remote changes or guarantee that disconnecting stops a remote process.

Before sharing diagnostics, remove hostnames/IP addresses, usernames, home-directory paths, tokens, SSH keys, connection exports, prompts and tool output that contain private information.
